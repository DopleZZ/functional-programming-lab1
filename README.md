Функциональные парадигмы на задачах Project Euler №3 и №28


## Подробно о заданиях и вариантах реализации

Для каждой задачи представлены несколько функциональных стилей. Ниже сопоставление файлов и требований.

### 1. Хвостовая рекурсия
Задача #3: `3/tail_recursive.hs` функция `primeFactorsTail` (аккумулятор собирает простые делители).
Задача #28: `28/tail_recursive.hs` функция `spiralSumTail` (аккумулятивное суммирование диагоналей).

### 2. Обычная рекурсия (нехвостовая)
Задача #3: `3/recursive.hs` функции `smallestFactor`, `primeFactorsRec` (рекурсивный шаг раскладывает число).
Задача #28: `28/recursive.hs` (рекурсивное добавление слоёв спирали).

### 3. Модульная конвейерная реализация (генерация + фильтрация + свёртка)
Задача #3: `3/modular.hs` — генерация кандидатов, фильтр делителей, проверка простоты и свёртка для максимума.
Задача #28: `28/modular.hs` — генерация слоёв спирали и суммирование их углов через конвейер.

### 4. Использование отображения (map)
Задача #3: `3/map_based.hs` — применение `map` для маркировки делимости и последующего отбора.
Задача #28: `28/map_based.hs` — построение углов каждого слоя через `map` по размерам.

### 5. Списковые включения / comprehension
Задача #3: `3/list_comp.hs` — одно включение порождает и фильтрует кандидаты.
Задача #28: `28/list_comp.hs` — генерация всех углов слоёв спирали списковым синтаксисом.

### 6. Бесконечные ленивые списки (где применимо)
Задача #3: `3/infinite_primes.hs` — бесконечный список простых чисел (решето) ограничивается факторизацией.
Задача #28: `28/placeholder.hs` — ленивое формирование слоёв спирали (потенциально бесконечная последовательность).

### 7. Закрытая формула (математическое свертывание)
Задача #28: `28/closed_form.hs` — использование аналитического выражения суммы диагоналей без итерации.

### 8. Императивное сравнение (традиционный язык)
Обе задачи: `3/compare.py`, `28/compare.py` — Python-реализации для сравнения подходов (итеративный стиль).

## Ожидаемые результаты
Задача #3 (largest prime factor of 600851475143): `6857`.
Задача #28 (sum of diagonals in 1001×1001 spiral): `669171001`.

Эти значения проверяются в тестах `lab1/test/Spec.hs` через функции `largestPrimeFactor` и `spiralDiagonalsSum`.

## Краткие идеи реализаций
- Tail recursion: минимизация роста стека за счёт аккумулятора.
- Нехвостовая рекурсия: подчёркивает чистый структурный вызов для наглядности шага факторизации / добавления слоя.
- Модульный конвейер: декларативное разделение «что генерируем», «что отбираем», «как сворачиваем». Легко расширять.
- Map: трансформация каждого кандидата в пару/значение для последующей фильтрации.
- List comprehension: компактность выражения всей логики генерации/фильтрации в одной конструкции.
- Ленивые бесконечные списки: отделение описания потенциально неограниченной последовательности (простые числа / слои) от потребления.
- Closed form: использование математики вместо вычислительного процесса.
- Императивное сравнение: подчёркивает различие между пошаговыми циклами и декларативными выражениями.


## Выводы
Haskell даёт выразительные средства: гарды, ленивость, списковые включения, точечный и бесточечный стиль. Сравнение разных парадигм на двух задачах показывает, что переход от императивного цикла к декларативному конвейеру упрощает чтение и вносит возможность быстрой замены стратегии (например, смена факторизации на использование бесконечного списка простых).
